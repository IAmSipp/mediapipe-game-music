# ผลทดสอบ Hand Piano Endless

วันที่ 19 พฤศจิกายน 2026 บน Windows x64 / Python 3.13.1, MediaPipe 1.2.3, Pygame 2.6.1, OpenCV 4.11.0, NumPy 2.2.6

## ทดสอบจำลอง

คำสั่ง `.venv\Scripts\python.exe -m unittest discover -s system/tests -v` ผ่าน 42 รายการ

- เริ่มจากเมนู ตีโน้ต จบจากพลาด และเล่นใหม่ผ่านลูป app จริง โดยจำลองเวลา ภาพกล้อง และเมาส์ ทั้ง `USE_PRESET = True` และ `False`
- จำลองตีถูก 1,000 โน้ตต่อเนื่องนานกว่า 500 วินาที เกมยัง PLAYING สุ่มครบสามช่องและทุกเสียงใน NOTE_POOL คิวโน้ตไม่โตตามจำนวนที่เล่น
- ตรวจว่ารอบใหม่สุ่มลำดับใหม่ ความเร็วเพิ่มต่อเนื่อง โน้ตมาถี่ขึ้นจนถึง MIN_NOTE_INTERVAL และตั้ง ACCELERATION = 0 ให้ความเร็วคงที่ได้
- ใช้ landmarks สังเคราะห์เล่น 60 วินาทีทั้ง preset และเขียนเองที่ 15/30/60/144 FPS รวมเวลาค้างของ preset ไม่พลาดและไม่จบรอบเอง
- ใช้สามท่าสำหรับสามช่อง แบมือสองข้างไม่เริ่มหรือเล่นใหม่ ต้องกดเมาส์ ปุ่มเริ่มใช้ไม่ได้เมื่อกล้องไม่พร้อม
- ตรวจกำซ้าย/ขวา/สองข้าง ท่ามือสำเร็จรูปอื่น ท่าร่างกาย ความขัดแย้ง การไม่พบมือ และความมั่นใจต่ำ
- ตรวจการแยก preset/เขียนเอง การไม่อ่านค่าของอีกแบบ ช่วงรับก่อน/หลังเส้น โบนัสตรงจังหวะ ท่าเร็ว/ผิด/ช้า และถือท่าเดิมไม่ตีซ้ำ
- จำลองเฟรมค้าง 1,000,000 วินาที ต้องจบเมื่อพลาดครบ ไม่สร้างโน้ตชดเชยเป็นคิวมหาศาล และไม่ย้อนใช้ท่าปัจจุบันตีโน้ตเก่า
- เล่นใหม่ล้างคะแนน เวลา ความเร็ว คิวโน้ต นาฬิกาเกิดตัวถัดไป เสียง และตัวกรองคำสั่ง
- ตรวจคลื่นเสียง ความถี่ C4 ความยาว ระดับเสียง การหยุดเสียง และไม่มีอุปกรณ์เสียง ใช้เสียงจำลอง ไม่ใช่ยืนยันด้วยหูผู้เล่น
- ตรวจภาพเมนู กำลังเล่น จบเกม แบบเขียนเอง และกล้อง/โมเดลไม่พร้อม ด้วยฟอนต์ไทย ไม่มีข้อความตัดในค่าตั้งต้น
- ตรวจ literal settings ไม่มี comments/docstrings ใน Python ของ system และคืนกล้อง/โมเดล/หน้าต่างเมื่อออกหรือเกิดข้อผิดพลาด

## กล้องจริงรุ่น endless

เปิด app กับกล้อง 0 และหน้าต่างจริง ทดสอบล่าสุดโดยจำลองเฉพาะคลิกปุ่ม ไม่บันทึกภาพกล้อง:

| การควบคุม | สถานะที่ผ่าน | เฟรมกล้อง | ความเร็วหลังเล่นใหม่ | คะแนนหลังเล่นใหม่ | คืน resources |
|---|---|---|---|---|---|
| Preset | MENU → PLAYING → GAME_OVER → PLAYING → ออก | 186 | 240 | 0 | ครบ |
| เขียนเอง | MENU → PLAYING → GAME_OVER → PLAYING → ออก | 186 | 240 | 0 | ครบ |

ไม่มี camera/model error และไม่ถึงเวลาหมดรอทั้งสองรอบ การเปิดกล้องใน sandbox เคยไม่สำเร็จ จึงทดสอบกล้องจริงนอก sandbox

ยังไม่ได้ให้ผู้เล่นทำท่าทั้งสามหน้ากล้องจริง จึงยังไม่ยืนยันความแม่นยำ ความหน่วง และความสะดวกในการตีจังหวะของคนจริง การควบคุมสามช่องและการเล่น endless ระยะยาวตรวจด้วยข้อมูลสังเคราะห์
