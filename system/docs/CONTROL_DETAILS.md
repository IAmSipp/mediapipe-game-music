# การปรับการควบคุม

## สำเร็จรูป

ตั้ง `USE_PRESET = True` ใน `setting/control_settings.py` แล้วเลือก `LEFT_ACTION`, `CENTER_ACTION`, `RIGHT_ACTION` ให้ต่างกัน ใช้สามท่าสำหรับสามช่อง เริ่มเกมหรือเล่นใหม่ด้วยปุ่มเมาส์

ท่ามือ: กำมือ, แบมือ, ชูนิ้วชี้, ชูสองนิ้ว, จีบนิ้ว เติม ซ้าย / ขวา / สองข้าง เช่น `กำมือสองข้าง` ต้องตรวจพบมือจริงครบสองข้างและทำท่าทั้งคู่

ท่าร่างกายจากต้นแบบยังใช้ได้: ยกแขน, เอียงตัว, เอียงศีรษะ เติม ซ้าย / ขวา ระบบเปิด Hand/Pose เฉพาะที่ต้องใช้ตามสามท่า

เมื่อตรวจท่าสองข้างสำเร็จ จะให้ความสำคัญเหนือท่ามือข้างเดียว จึงไม่ยิงซ้ายหรือขวาขณะกำสองมือ หากหลายท่าทับกันโดยไม่มีท่าสองข้างที่ชัดเจน จะไม่ส่งคำสั่ง ควรเลือกท่าที่แยกกันง่าย

`SENSITIVITY` อยู่ระหว่าง 0.5–1.5 ค่าสูงตรวจผ่านง่ายขึ้น `HOLD_SECONDS` ต้องไม่ติดลบและนับเวลาจริง เริ่มนับเมื่อพบผู้สมัครท่าใหม่ ค่าตั้งต้น 0.06 วินาทีเหมาะกับการตีจังหวะ

## เขียนเอง

ตั้ง `USE_PRESET = False` ระบบเรียก `get_note_command(hands, pose_landmarks)` จาก `setting/hand_controls.py` เท่านั้น ไม่อ่านหรือตรวจค่าชื่อท่า ความไว และเวลาค้างของสำเร็จรูป

ข้อมูลมือคือรายการ dict ที่มี `side` เป็น `Left` / `Right`, `landmarks` 21 จุด และ `confidence` แต่ละจุดมี x/y/z ข้อมูล Pose มี 33 จุด หรือรายการว่างเมื่อไม่ตรวจพบ เปิด `USE_POSE` เฉพาะเมื่อใช้ร่างกาย

คืน `LEFT`, `CENTER`, `RIGHT` หรือ `None` โดยตรวจเงื่อนไขสองข้างก่อนข้างเดียว และอัปเดตข้อความ `*_INSTRUCTION` ให้ตรงท่าที่เขียน

ตัวอย่างใช้ชูนิ้วชี้แทนกำมือ: แทนฟังก์ชัน `is_hand_closed()` ในไฟล์ผู้เรียนด้วยฟังก์ชันนี้ กฎเลือกช่องด้านล่างเดิมยังใช้ได้:

```python
def is_hand_closed(landmarks):
    wrist = landmarks[0]
    index_open = distance(landmarks[8], wrist) > distance(landmarks[6], wrist) * 1.15
    middle_closed = distance(landmarks[12], wrist) < distance(landmarks[10], wrist)
    ring_closed = distance(landmarks[16], wrist) < distance(landmarks[14], wrist)
    pinky_closed = distance(landmarks[20], wrist) < distance(landmarks[18], wrist)
    if index_open and middle_closed and ring_closed and pinky_closed:
        return True
    else:
        return False
```

การสลับกลับ True ไม่ลบโค้ดเขียนเอง แบบเขียนเองไม่มีตัวกรองเวลาค้างจากระบบสำเร็จรูป

## ปรับเกม endless

แต่ละโน้ตสุ่มหนึ่งในสามช่องและสุ่มเสียง MIDI จาก `NOTE_POOL` เช่น 60 คือ C4 เปลี่ยนกลุ่มเสียงเพื่อเปลี่ยนบรรยากาศ ไม่มีทำนองตายตัวหรือจำนวนโน้ตที่ทำให้จบเกม

`START_SPEED` คือความเร็วเริ่มต้นเป็นพิกเซล/วินาที `ACCELERATION` คือความเร็วที่เพิ่มในแต่ละวินาที ไม่มีเพดานความเร็ว ใช้ 0 เพื่อปิดการเร่ง `FIRST_NOTE_DELAY` คือเวลาถึงเส้นของโน้ตแรก ต้องมากพอให้โน้ตตกจากด้านบนได้ครบระยะ

`BPM` คือจังหวะเริ่มต้น เมื่อเร็วขึ้นโน้ตจะมาถี่ขึ้นจนถึงระยะห่าง `MIN_NOTE_INTERVAL` วินาที ค่านี้ต้องไม่เกิน 60/BPM และต้องมากกว่าสองเท่าของ `HIT_WINDOW_SECONDS` เพื่อไม่ให้ช่วงรับโน้ตติดกันทับกัน

`HIT_WINDOW_SECONDS` คือเวลารับก่อน/หลังเส้น ปรับ `PERFECT_WINDOW_SECONDS` เพื่อโบนัสตรงจังหวะ ท่าที่ทำเร็วไปหรือผิดช่องไม่ให้คะแนน การถือท่าเดิมไม่ตีซ้ำ ต้องคลายหรือเปลี่ยนท่า โน้ตที่เลยช่วงรับจะนับพลาด เกมจบเมื่อพลาดครบ `MAX_MISSES` เท่านั้น คะแนนและเสียงเกิดเฉพาะตีถูก
