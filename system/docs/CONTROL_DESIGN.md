# ระบบ Hand Piano

กล้องส่งภาพ RGB ที่ไม่กลับกระจกเข้า MediaPipe Tasks `HandLandmarker.detect_for_video()` และ `PoseLandmarker.detect_for_video()` โดย timestamp เพิ่มเสมอ จากนั้นจึงกลับภาพและพิกัดเพื่อแสดงผล ไม่เปลี่ยนป้ายข้างจริงของผู้เล่น

อ้างอิงทางการที่ตรวจเมื่อ 19 พฤศจิกายน 2026:

- [Hand Landmarker / Python](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Python): VIDEO, สองมือ, handedness และภาพไม่กลับกระจก
- [HandLandmark และ Tasks API source](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/tasks/python/vision/hand_landmarker.py): ข้อมือ 0, ปลายนิ้ว 8/12/16/20, PIP 6/10/14/18, โป้ง 4, MCP 5/17
- โมเดลทางการและ URL คงใน `system/download_model.py` โหลดผ่าน bytes เพื่อรองรับตำแหน่งไฟล์ภาษาไทย

## คำสั่งและจังหวะ

`GameControls` แยกเส้นทางสำเร็จรูปกับกฎผู้เรียนอย่างเด็ดขาด สำเร็จรูปเพิ่มท่าสองมือโดยประกอบผลซ้ายและขวาและให้ท่าสองมือเหนือท่าข้างเดียว ส่วนกฎผู้เรียนใช้ if/elif/else โดยตรง

`Game` สุ่มช่องและเสียงของโน้ตต่อเนื่อง ความเร็วเป็น START_SPEED + ACCELERATION × เวลาจริง ระยะทางเป็น START_SPEED × เวลา + 0.5 × ACCELERATION × เวลา² พิกัดโน้ตใช้ผลต่างระยะทางปัจจุบันกับระยะทางเป้าหมาย จึงเร่งลื่นโดยไม่มีการกระโดดเมื่อความเร็วเปลี่ยน และไม่สะสมความคลาดเคลื่อนจากการเลื่อนต่อเฟรม

ช่วงห่างของเวลาเป้าหมายลดลงตามความเร็วโดยมี MIN_NOTE_INTERVAL เป็นขอบล่าง ช่วงรับสองโน้ตจึงไม่ทับกัน เก็บคิวเฉพาะโน้ตที่ใกล้เข้าหน้าจอกับอีกหนึ่งตัวล่วงหน้า ไม่สร้างเพลงทั้งรอบ เมื่อเฟรมค้างนานจะนับพลาดเรียงตามเวลาและหยุดทันทีเมื่อถึงจำนวนจบเกม ไม่สร้างคิวหลายล้านตัวเพื่อชดเชยเวลา Input ที่เพิ่งตรวจพบใช้กับเวลาปัจจุบัน ไม่ย้อนตีโน้ตระหว่างเฟรมที่ค้าง

การเปลี่ยนคำสั่งเป็น LEFT/CENTER/RIGHT คือการตีหนึ่งครั้ง ช่วงรับวัดเป็นวินาทีก่อนและหลังเวลาเป้าหมาย ถือท่าเดิมข้ามโน้ตไม่ได้คะแนนซ้ำ ไม่เก็บท่าที่ทำเร็วเกินไว้ตีอัตโนมัติ ไม่หักคะแนนเพิ่มจากท่าผิด แต่โน้ตที่หลุดจะนับพลาด

ใช้สามท่าสำหรับสามช่อง เริ่มเกมและเล่นใหม่ด้วยปุ่มเมาส์เมื่อมีภาพกล้องพร้อม การเริ่มรีเซ็ตเวลา ความเร็ว คะแนน คิวโน้ต เวลาเกิดตัวถัดไป เสียงค้าง และตัวกรองคำสั่ง แล้วสุ่มรอบใหม่ เวลารอเมนูไม่ไหลเข้ารอบใหม่ เกมจบเมื่อพลาดครบเท่านั้น

## ภาพและเสียง

หน้าจอคง 1120×760 เกมซ้าย กล้องขวา ชื่อครั้งเดียว ปุ่มเมาส์ เรียบง่ายตามต้นแบบ เสียงเปียโนสังเคราะห์จากคลื่นหลายฮาร์มอนิกและซองเสียงลดระดับ ไม่ใช้เพลงหรือเสียงจากภายนอก ไม่มีอุปกรณ์เสียงก็เล่นต่อได้

`PianoSound` อยู่ใน app ส่วนเกมส่งเฉพาะ MIDI ที่ตีถูก `pygame.quit()` คืนเสียงและหน้าต่าง `HandCamera.close()` คืนกล้องและโมเดลทั้งเมื่อออกและเมื่ออ่านภาพผิดพลาด ผลทดสอบที่สร้างขึ้นอยู่ใน artifacts เท่านั้น
