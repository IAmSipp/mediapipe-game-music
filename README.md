# Hand Piano — เกมเปียโนสามช่องด้วย MediaPipe

เกม endless สุ่มโน้ตลงมาสามช่องต่อเนื่อง ความเร็วตกเพิ่มขึ้นตามเวลาและโน้ตมาถี่ขึ้น ทำท่าเมื่อ **ขอบล่างของโน้ตถึงเส้นล่าง** แล้วคลายหรือเปลี่ยนท่าก่อนตัวถัดไป ตีถูกได้คะแนนและเสียงเปียโน เล่นได้เรื่อย ๆ จนพลาดครบ 5 ตัว

| ช่อง / หน้าที่ | ท่าเริ่มต้น |
|---|---|
| ซ้าย | กำมือซ้าย |
| กลาง | กำมือสองข้าง |
| ขวา | กำมือขวา |
| เริ่ม / เล่นใหม่ | กดปุ่มเมาส์ |

ซ้าย/ขวาหมายถึงข้างจริงของผู้เล่น ภาพกล้องและจุดแสดงผลเป็นกระจก

## ติดตั้งและเปิดเกม

Windows 64-bit / Python 3.13 ใช้ PowerShell ในโฟลเดอร์เกม:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m system.download_model
.\.venv\Scripts\python.exe main.py
```

เครื่องที่เตรียม `.venv` แล้วใช้เฉพาะคำสั่งสุดท้าย กล้องอื่นเลือก `main.py --camera 1` กด Esc หรือปิดหน้าต่างเพื่อออก หากเปิดกล้องไม่ได้ ให้ปิดแอปอื่นที่ใช้กล้องแล้วเปิดเกมใหม่

## ปรับแต่ง

ผู้เรียนแก้ใน `setting/` อ่าน [คู่มือสั้น](setting/README.md)

- `control_settings.py`: `USE_PRESET = True` เลือกสามท่า ชื่อท่า ความไว และเวลาค้าง
- `hand_controls.py`: `USE_PRESET = False` ใช้เฉพาะกฎที่เขียนเอง ค่าของสำเร็จรูปจะไม่ถูกใช้
- `game_settings.py`: ความเร็วเริ่มต้น อัตราเร่ง จังหวะ ระยะห่างขั้นต่ำ คะแนน จำนวนพลาด กลุ่มเสียงสุ่ม ขนาด สี และเสียง

`main.py` เปิดเกมเท่านั้น ระบบ กล้อง โมเดล การวาด และการทดสอบอยู่ใน `system/` คงโครงสร้างจากต้นแบบ

## ทดสอบ

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s system/tests -v
```

ชุดทดสอบใช้กล้องจำลองและโมเดลจริงกับภาพว่าง แยกจากการลองกล้องจริง อ่าน [ผลทดสอบ](system/docs/TEST_REPORT.md) และ [รายละเอียดการควบคุม](system/docs/CONTROL_DETAILS.md)

macOS/Linux ยังไม่ได้ทดสอบ ใช้ `.venv/bin/python` และต้องมีฟอนต์ไทย เช่น Noto Sans Thai
